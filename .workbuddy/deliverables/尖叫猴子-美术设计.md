## 1. 设计目标与硬件约束

- 目标设备：FoloToy AI Passport（ESP32-C3，无 PSRAM），屏 ST7789 **240×320 竖屏 RGB565**
- 风格：**像素风森林草地**，明亮卡通调子，深色描边保证小屏可读性
- 约束：无文件系统分区 → 全部素材以 **RGB565A8 const 数组**编译进固件（色平面 w×h×2B + alpha 平面 w×h×1B，Flash 直读、零 RAM 副本、LVGL9 原生 blit 免解码）
- 精灵源格式：字符调色板矩阵（每精灵 ≤8 索引色），便于 diff/review/迭代

## 3. 角色：像素猴（24×24，6 帧）

### 3.1 造型规格
- 大头小身：头占 0–13 行（14 行），躯干 14–20 行，腿 21–22 行
- 卷尾在身体左侧（18–19 行，跑 2 帧时尾尖抬起）
- 面向右（跑动方向）；眼位偏右表现朝向
- **碰撞盒**：相对精灵内缩 4px（AABB，用于石头/仙人掌判定；悬崖判定用脚底点）

### 3.2 帧表
| 帧 | 触发条件 | 差异点 | 动画参数 |
| --- | --- | --- | --- |
| monkey_run1 / run2 | 着地跑动 | 腿摆相位互换；run2 尾尖上抬 | 10fps 循环 |
| monkey_jump_up | vy<0 | 双腿收拢 | 单帧 |
| monkey_jump_down | vy>0 | 双腿下垂 | 单帧 |
| monkey_hurt | 受击后 1.2s | X 眼 + 额头淤青 + 张嘴 | 8Hz 透明度闪烁（无敌期） |
| monkey_death | 游戏结束 | X 眼 + 吐舌 + 尾巴摊平 + 四肢摊开 | 定格，结算面板放大展示 |

### 3.4 动效补充
- 跑动时整体 y 随地面；跳跃由物理驱动（分贝→初速），非美术帧决定高度
- 受击除闪烁外加 80ms 全屏红闪（纯色叠加层）

## 4. 场景（实景区 + HUD，240×320 竖屏）

### 4.1 屏幕分区
```
y=0..26    HUD：里程(左) + 心形血量×3(中) + 电量角标(右下角，仅标题屏)
y=27..120  右缘 x=214..236：竖直 dB 柱 12 段（阈值刻度线在 50）
y=0..230   实景区上部：天空、云、树
y=231..320 地面与土层（实景区内地面顶为统一基准线）
```
> 实际实现坐标以 `game_monkey_config.h` 为准；预览页按 240×90 实景区等比演示。

### 4.2 视差层
| 层 | 内容 | 速度 |
| --- | --- | --- |
| 云 | 16×6 精灵 ×2 循环回绕 | 0.25× |
| 树 | 16×16 精灵排成中景树列，间距 44–56px 抖动 | 0.5× |
| 草纹理/土纹理 | 短划/点阵随地面 1× 滚动 | 1× |

### 4.3 悬崖绘制规则
1. 地面段（草+土）在缺口区间整段移除
2. 缺口两侧画 2px 土深色崖壁 + 1px 亮边（#6B4A2E）
3. 缺口内部填充崖坑深色 #2B1B0E（视觉"深渊"）
4. 猴子脚底 x 落入缺口且 y≥地面线 → 坠落即死（切 jump_down 帧 + 下坠）

## 6. HUD 与界面视觉
- **dB 柱状图**：右缘竖直 12 段，每段 10×22px 圆角矩形；点亮色按段位绿(0–50)/橙(50–80)/红(80–100)，未点亮段同色 18% 不透明度；阈值 50 处墨色 2px 刻度线 + 「50」标注；柱顶「分贝」标注
- **血量**：心形 10×10 精灵 ×3，失去时灰化（用 18% 红替代实心）
- **标题屏**：24px 标题字「尖叫猴子」+ 猴子 run 动画立绘（居中 2× 放大）+ Top5 榜单列表 + 「按 OK 开始」呼吸闪烁 + 右下角电量
- **结算面板**：180×112 居中卡片（HUD 纸色 + 墨描边），死亡原因（被砸晕了 / 掉下去了）+ 本局里程 + 名次（新纪录时金星粒子 + 「新纪录!」红字）
- **字体**：Noto Sans SC（SIL OFL 1.1）→ lv_font_conv 子集：正文 16px（约 40 汉字+ASCII），标题 24px（仅标题 4–6 字）；字符集来自 UI 文案常量数组，逐码点自检

## 9. 待确认决策点（评审清单）
1. **猴子比例体态**：当前 24×24 大头小身卷尾——是否 OK？
2. **调色板明度**：当前明亮卡通森林——偏好更艳/更灰？ 
3. **死亡表现**：当前 X 眼吐舌四肢摊开——备选平躺仰面？
4. **dB 柱位置**：当前右缘竖直 12 段——备选顶部水平条？
5. **装饰元素**：是否加花/蘑菇/蝴蝶点缀中景与草地？
