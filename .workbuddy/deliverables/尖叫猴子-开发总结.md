## 一、这是什么

FoloToy AI Passport（ESP32-C3，240×320 竖屏，无 PSRAM）上的**麦克风声控像素跑酷游戏**：
- 猴子自动向右跑，**对着麦克风喊叫决定跳跃高度**（连续映射：越过阈值 50 的瞬间起跳，越响跳越高，开局自动噪声校准）
- 障碍三类：石头（撞=掉血+15 秒减速）、仙人掌（撞=掉血，血尽终局）、悬崖缺口（坠落即死）
- HUD：里程 + 3 颗心 + 右缘 12 段 dB 柱状图（绿 0-50/橙 50-80/红 80-100，阈值刻度线）
- 计分：跑酷里程，**本地 NVS Top5 榜单**（重启不丢）
- 界面全中文（自建 Noto Sans SC 子集字库），开机自建两屏（标题/游戏），**完全替换了 demo 测试菜单**

## 四、核心机制速记

**音频链路**（单 worker 任务，优先级 4）：
```
每 15ms: bsp_audio_read(240帧) → [有音效? 写 240 帧音效 + 检测器 hold] : [检测器 push → s_level]
```
- 读/写交错，无盲区；音效期间 level 冻结（防扬声器回授）；`set_format` 只调一次（BSP 会 close/reopen）
- 触发：世界 tick 内读 `s_level`，滞回 `SHOUT_ON=50` 触发 / `SHOUT_OFF=38` 复位，着地才起跳

**跳跃映射**（连续）：`v0 = 270 + (level-50)*(540-270)/45` px/s → 跳高 27~108px（重力 1350）

**障碍**：热身 8s 后生成；权重 石 0.40 / 仙人掌 0.35 / 悬崖 0.25；间隔 ≥176px（最大滞空距离+40px 反应余量）；种子化 LCG，宿主测试确定性

**渲染**：~50 个 LVGL 对象（精灵 const 数据直读 flash，零 RAM 副本），世界 tick 在 LVGL 任务内的 lv_timer 跑（算画同任务不加锁）；悬崖用"遮盖块"实现（坑体+左右崖壁 6 个对象池）

## 九、本机环境的坑（重要，免得重新踩）

1. **宿主编译器**：本机无 cc/gcc，用 zig 0.16 包装器 `.workbuddy/bin/cc`；跑 validate.sh 要 `PATH=".workbuddy/bin:$PATH"`；zig 会在 cwd 留 4 字节 `blat` 垃圾，跑完 `rm -f blat*`
2. **actionlint**：装在 `~/esp/bin/actionlint.exe`（GitHub 直连被墙，用 ghfast.top 代理下载）；`ACTIONLINT_BIN=~/esp/bin/actionlint.exe`；**别放 /tmp（会被系统清）**
3. **python tempfile/删除**：WorkBuddy 注入的 sitecustomize 是「安全删除」（删除进回收站），会破坏 tempfile 探测与测试目录清理；`~/esp/tmp` 又受 TSD 管理。跑门禁必须 `PYTHONPATH="$(cygpath -w /tmp/smsite)"`（shim：tempfile 指向系统 %TEMP% + os.unlink/rmdir 失败时外部 rm 兜底 + 先删符号链接）。两个语义坑：rmdir 的 ENOTEMPTY 不能升级递归删除；符号链接引用目标时先删链接
4. **--static 也要免沙箱跑**（和 --firmware 一样）
5. **组件管理**：`managed_components/` 已就位（proj-build 副本 + lvgl 9.5.0 + `.component_hash` 写回），构建前 `grep -rl TSD-Header managed_components/ | wc -l` 必须为 0；别动 `dependencies.lock`
6. **字体源 OTF**：在 `.workbuddy/fonts/`（TSD 不加密 node 写的文件；python 写 .txt/.csv 会被加密——所以生成工具全用 node）
7. **仓库根有一批随机名垃圾文件**（安全删除中转残留），已确认全部未跟踪、不影响代码与固件；可用资源管理器直接删，或 `git clean -fd`（较慢，TSD 逐文件锁）
8. 工作日志/开发计划/美术设计文档都在 `（仓库）/.workbuddy/` 下（gitignored）：`memory/2026-10-10.md`、`尖叫猴子-开发计划.md`、`deliverables/尖叫猴子-美术设计.md`、`尖叫猴子-美术预览.html`、`sm_art_matrices.mjs`
