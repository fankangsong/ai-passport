# 《尖叫猴子》(Screaming Monkey) 游戏开发计划

## 一、任务与已确认决策

在 FoloToy AI Passport（ESP32-C3）上开发麦克风声控像素跑酷游戏：猴子自动向右跑，喊叫分贝决定跳跃高度，躲避石头（疼+减速15s+掉血）/悬崖（即死）/仙人掌（掉血），里程打榜。

**用户已拍板**：连续分贝映射（开局自动噪声校准）｜本地 NVS Top5｜芯片音效（无BGM）｜设计文档+代码实现（不出AI概念图）。
**小项默认值**（不阻塞）：Noto Sans SC 的 OTF 源不入 git（README 记来源+哈希）；设备无 RTC 时榜单日期显示 `--`。
**美术基准**：视觉/精灵/布局规格以《尖叫猴子-美术设计.md》v1 为准（2026-10-10 评审稿；同目录 `尖叫猴子-美术预览.html` 可动画预览，`sm_art_matrices.mjs` 为精灵矩阵唯一源）；本文涉及美术的数值已同步。

## 二、关键事实（已探索核实）

- **硬件**：ESP32-C3 单核@160MHz、8MB Flash、无 PSRAM；屏 ST7789 240×320 竖屏 RGB565，LVGL 9.5（池仅 24KB）；三键 ADC（UP/DOWN/OK，PRESS 低延迟事件）；NVS 可用；无文件系统分区（素材必须编译进固件）。
- **麦克风**：ES8311 I2S0 全双工，`bsp_audio_read()` 阻塞读 PCM（16k/16bit/单声道，输入增益固定 30dB）；**bsp 层无锁，读写串行化责任在调用方**；`bsp_audio_set_format()` 会 close/reopen——只能调一次。扬声器只播裸 PCM，无解码器。
- **无中文字体**：仅 Montserrat 14/20，需 lv_font_conv 生成子集。
- **黄金参考**：本仓库提交 `1637888`（workbuddy/main-94509a8a 分支）「吹气球」麦克风游戏——已验证的检测器（DC去除+噪声地板+RMS+非对称EMA）、Q16.16 物理、SFX 运行时合成、中文子集字体（Noto Sans SC，SIL OFL）、host 测试注册、音频分时复用。经 `git show 1637888:<path>` 提取模式，**不合并**该分支。
- **环境**：ESP-IDF 5.5.3 已装（`. /c/Users/fanks/esp/activate-idf.sh` 激活）；设备串口 COM4；TSD 防泄密软件加密 Python 写出的文件 → 生成类工具用 node（lv_font_conv/gen_sprites 用 node 实现），`validate.sh --firmware` 需沙箱外运行，构建后 `dependencies.lock` 必须无 diff。
- **Git**：当前 workbuddy/origin-main-732ef0d8（=origin/main），工作区干净，无未提交修改需保留。
- **五个必需 skill 已可用**：passport-develop/setup/build/device-test/debug + 本机 passport-idf-env，按 passport-develop 工作流执行。

## 四、游戏模型（纯C可测）

**状态机**：`CALIB`(采20块/300ms环境噪声定地板) → `READY`(1800ms 倒计时) → `RUN` ⇄ → `OVER`(死亡原因+里程+榜单)。RUN 内修饰位：`slow_left_ms`（15s 减速）、`invuln_ms`（受击后1.2s无敌防连撞）。

**核心 API**：`sm_world_init/begin_run/tick(dt_ms)/try_jump(level)/last_event()/meters()`；定点 Q16.16 半隐式欧拉。

**物理参数**（全进 config.h）：

- 重力 1350 px/s²；跳跃初速 `v0 = 270 + (level-50)*(540-270)/45` px/s（clamp 50..95 level）→ 跳高 27~108px，滞空 0.40~0.80s
- **触发：上升沿 + 当次 level 决定跳高**（滞回：`SHOUT_ON=50` 触发 / `SHOUT_OFF=38` 复位；空中不触发；不做二段跳）
- 速度 90→170 px/s 线性爬坡 120s；减速期 ×0.55；`PX_PER_METER=8`
- 障碍：warmup 8s 后生成，权重 石0.40/仙人掌0.35/悬崖0.25，LCG 伪随机（种子注入可测），间隔 = speed×rand(1.1~2.0s) 且 ≥ 水平跳距+40px；悬崖缺口 34~58px；AABB 碰撞（猴盒内缩 4px）；悬崖判定=着地时 x 在缺口内→即死

## 五、音频方案

**单 worker 任务**（优先级4/栈4096，沿用已验证的 stop 握手模式），每轮 ~15ms 交错：

```
read 240帧(15ms,恰对齐DMA描述符) → SFX活跃? 喂 sfx_buf ≤240帧到 write（TX DMA 实时消耗不积压）
  + 检测器进 hold（只跟踪DC/地板，level 冻结+快衰减，防扬声器回授）
  : 正常检测 → s_level(volatile)，上穿沿置 s_shout_req
```

无盲区（优于吹气球的暂停丢块方案）；`set_format` 仅启动时一次；SFX 音量 65%。

**检测器**：复用吹气球算法签名——`sm_detector_init/push(返回0..100 level)/reset_session/hold`；EMA attack 48/release 13 (Q8)，柱状图数据源即 `s_level`。

**触发判定**：世界 tick（LVGL 任务内）每 33ms 读 `s_level`，滞回+着地判定 → `try_jump(level)`。延迟预算 ~110ms（喊叫类输入可接受）。

**SFX 运行时合成**：`sm_sfx_render(fx, buf, max_samples, rate)`，static 缓冲 6400 样本（12.8KB），队列深度4丢满不阻塞：
jump=方波300→700Hz上滑90ms｜land=三角220Hz 60ms｜hurt=方波200→120Hz+噪声前缀 140ms｜death=392/311/262Hz下行三连｜record=523/659/784/1047Hz上行琶音（各≤400ms、25%满幅、5ms淡入淡出）

## 六、渲染方案

**对象化渲染**（canvas 240×200 需 96KB RAM 已否决）：约 35 个对象（lv_image const 精灵 + lv_obj 色块池），世界 tick 在 **LVGL 任务内的 lv_timer(33ms)** 跑——算和画同任务无需加锁；音频任务只碰 volatile/队列不碰 LVGL。渲染缓存纪律：标签/柱状图/坐标变化才刷。

**美术基准**（详见《美术设计》）：22 色全局调色板（角色 7 / 场景 10 / 障碍与 UI 若干，深棕描边 #4A2F14 统一轮廓）；动效全部为 LVGL 对象动画零新增素材——落地尘土粒子、受击全屏红闪 80ms、受伤无敌期 8Hz 闪烁、破纪录金星粒子、减速期头顶「晕」小标签、结算面板滑入。

**精灵格式**：字符调色板矩阵源（`sm_art_matrices.mjs`，每精灵 ≤8 索引色 + 透明，与美术预览页同源）→ `tools/gen_sprites.mjs` 展开 **RGB565A8** const 数组（LVGL9 原生 blit 免解码、零 RAM 副本）。猴子 24×24 六帧（run×2 / 跳升×1 / 跳降×1 / hurt / death）≈10.4KB，石头 16×16 = 0.8KB、仙人掌 12×24 = 0.9KB、心 10×10 = 0.3KB、树 16×16 + 云 16×6 ≈ 1.0KB，**合计 ≈13.4KB**（美术设计 §8）。

**猴子帧表**（美术设计 §3）：run 2 帧（腿摆相位互换，run2 尾尖上抬，10fps 循环）｜跳升 1 帧（双腿收拢，vy<0）｜跳降 1 帧（双腿下垂，vy>0）｜受伤 1 帧（X 眼+额头淤青+张嘴，1.2s 无敌期 8Hz 闪烁）｜死亡 1 帧（X 眼+吐舌+尾巴摊平+四肢摊开，结算面板放大定格）。碰撞盒相对精灵内缩 4px。

**地面/悬崖**（美术设计 §4.2/4.3）：地面由短段 lv_obj 池滚动回绕（草顶 4px #82BE2D + 深划 #55951D，土层 #75452E + 深点 #4A2C1B，纹理 1× 滚动）；生成悬崖时该区间段整段移除 + 两侧 2px 土深崖壁（#4A2C1B）+ 1px 亮边（#6B4A2E）+ 坑内 #2B1B0E。视差 2 层：云 16×6 精灵 ×2 循环回绕（0.25×）、中景树 16×16 精灵列立于地面顶（间距 44–56px 抖动，0.5×）。

**HUD（240×320 竖屏，美术设计 §4.1/§6）**：y=0..26 「里程 N 米」(左，sm_font_16) + ♥×3（中，10×10 lv_image，失去时 18% 红灰化）；y=27..120 右缘 x=214..236 **竖直 12 段 dB 柱状图**（绿 0–50/橙 50–80/红 80–100，未点亮段同色 18% 不透明度，阈值 50 处墨色刻度线 +「50」标注）；**地面顶基准线 y=231**（草+土至屏底），猴子 x=36、脚底 y=231（跳高上限 108px 时顶部余量充足）；标题屏=24px「尖叫猴子」+猴子立绘(2×)+Top5+「按OK开始」呼吸闪烁+右下角电量角标（仅标题屏显示）；结算面板=180×112 居中（HUD 纸底 #F4F4EA + 墨描边）死亡原因（被砸晕了/掉下去了）/里程/名次，新纪录金星粒子 +「新纪录!」红字。

**帧率**：目标 30fps；掉帧则 `SM_UI_TICK_MS=42` 降 24fps。

## 十一、风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 单核 CPU：LVGL 渲染+SPI 为大头 | 小步位移、局部失效、24fps 降级开关、真机 esp_timer 打点 |
| Flash：素材 ≈66KB（精灵 13.4 + 字体 52） | app 分区 8128KB 富余 >99%；`idf.py size-components` 复核 |
| RAM：sfx_buf 12.8KB static + LVGL 对象 ~6KB 堆 | 全静态/小对象；进页打印 free heap；C3 ~400KB 内部 RAM 充裕 |
| 音频读写竞争（bsp 无锁） | 单 worker 顺序交错；set_format 仅一次 |
| 扬声器回授误跳 | SFX 期检测 hold + 音量65% + 校准静音 + 阈值50；真机专项验收 |
| TSD 加密 Python 写文件 | 生成类工具全用 node；构建后 diff dependencies.lock 必须为空；--firmware 沙箱外跑 |
| contract 测试解析 main.c | key_guard 段逐字保留，改造后立即 --static |
